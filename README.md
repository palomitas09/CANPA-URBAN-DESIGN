# CANPA Urban Design · Configurador 3D

Plataforma municipal B2G amb configurador 3D (Three.js) de mòduls urbans Plug & Play,
galeria de renders, comparador abans/després i exportació a STL per imprimir maquetes a escala.

Versió millorada: `canpa_urbankit_b2g_configurador_3d_i_plataforma_municipal.html`
(versions anteriors: `index.html` i `index2.html`).
